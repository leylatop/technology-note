 适用场景：
 mac 电脑一般会自带一个 python
 - python 的位置是 `/usr/bin/python3`
 - pip 的位置是  `/usr/bin/pip3`
 - 别名是 `python3` 和 `pip3`
当 mac 电脑自带的 python 版本过于老旧不能适配最新依赖包的时候，一般需要安装最新版本的 python，但是安装完之后，新手可能分不清 mac 上到底有几个 python。

## 第一步：查清楚到底有几个 Python 路径
```
where python python3 python3.14
```

你可能会看到的输出示例及含义：
- **`/usr/bin/python3`**：这是 **macOS 系统自带** 的版本（通常是 3.9.6）。**绝对不要动它。**
- **`/usr/local/bin/python3.14`**：这是你安装的版本。这是你以后主要使用的版本。
- **`/usr/local/bin/python3`**：这通常是一个快捷方式，可能指向系统版，也可能指向 Homebrew 版。

## 第二步：查清楚每个命令对应的具体版本号
- `python --version`（看你的别名是否生效）
- `python3 --version`（看系统默认的 Python3 是多少）
- `python3.14 --version`（确认你的新版是否存在）


## 第三步：理清它们之间的关系
| **身份**     | **典型路径**                    | **建议态度**                        |
| ---------- | --------------------------- | ------------------------------- |
| **系统管理员**  | `/usr/bin/python3`          | 它是给 Mac 自己用的，咱们**别碰它**，也别往里装包。  |
| **你的开发主力** | `/usr/local/bin/python3.14` | 这是你的工具，咱们通过**别名**或者**虚拟环境**来用它。 |
| **项目私家医生** | `你的项目目录/.venv`              | 这是**最干净**的用法。每个项目一个，用完即删。       |

## 其他

- 查看安装了哪些包的命令
```bash

/usr/bin/pip3 list # 查看 Mac 自带的 python 安装了哪些全局包

pip list # 查看你安装的python安装了哪些全局包
```
